# Assignment Mode Skill

This skill activates when the user is working on a university assignment that requires code development and report generation.

## When to Activate

Activate this skill when the user:
- Mentions "assignment", "coursework", "lab report", "homework", "submission"
- Asks to generate a DOCX report
- Asks to write code for a university task
- Mentions any course-specific tool or language
- Says "generate report", "create docx", "make report"
- Asks about assignment formatting or structure

## Workflow

### Phase 1: Setup
1. Read `templates/report_config.json` for student details
2. Read `templates/task.md` for assignment requirements
3. Confirm understanding with the user

### Phase 2: Code Development
1. Write the source code in the appropriate language
2. Follow the conventions of the chosen language
3. Add proper comments and program header
4. Test by asking user to build and run

### Phase 3: Testing
1. Ask user to build/compile in their tool
2. If errors occur, read the error and fix the code
3. Ask user to run with test input
4. Verify output is correct

### Phase 4: Screenshots
1. Ask user to take screenshots of:
   - Code view in editor (top and bottom halves)
   - Compilation/assembly output
   - Run button / execution start
   - Console output with results
   - Errors (if any occurred and were fixed)
2. Screenshots must be saved in `screenshots/` folder as PNG files

### Phase 5: Report Generation
1. Run: `python3 assets/generate_report.py`
2. The script reads `templates/report_config.json` for metadata
3. Auto-embeds screenshots from `screenshots/` folder
4. Generates `report_final.docx` with all sections
5. Tell user to review and submit

## Key Files

| File | Purpose |
|---|---|
| `templates/report_config.json` | Student/course metadata (generated by setup.py) |
| `templates/task.md` | Assignment task description |
| `assets/generate_report.py` | DOCX report generator |
| `assets/bup_logo.png` | University logo for cover page |
| `screenshots/` | User saves screenshots here |
| `report_final.docx` | Generated report output |

## Report Formatting

All reports use:
- Font: Times New Roman, 12pt
- Color: Black (no colored text)
- Line spacing: 1.5
- Academic formal tone
- Figure numbering for screenshots
- Table Grid style for tables
