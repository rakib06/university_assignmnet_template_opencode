# Assignment Template — Quick Start Guide

A complete template for university assignment development using **opencode**. Write code, take screenshots, generate a professional DOCX report — all from the command line.

> **New here?** See the [Quick Start Guide](QUICKSTART.md) for a 5-minute overview.

---

## What This Template Does

This template provides a complete workflow for:

1. **Writing code** for any university assignment (assembly, Python, C, Java, etc.)
2. **Building and running** the code in your development environment
3. **Taking screenshots** of the code, compilation, and output
4. **Generating a professional DOCX report** with embedded screenshots, academic formatting, and proper structure

The generated report follows university standards:
- **Font:** Times New Roman, 12pt
- **Color:** Black text throughout
- **Tone:** Formal academic language
- **Structure:** Cover page, TOC, introduction, code explanation, screenshots, conclusion
- **Images:** Auto-scaled with preserved aspect ratios

## Prerequisites

### On a New Machine

Before using this template, install the following:

### 1. Python 3.8+

```bash
# Check if Python is installed
python3 --version

# If not installed (Ubuntu/Debian):
sudo apt update && sudo apt install python3 python3-pip

# If not installed (macOS with Homebrew):
brew install python3

# If not installed (Windows):
# Download from https://www.python.org/downloads/
```

### 2. Required Python Packages

```bash
pip install python-docx Pillow
```

- `python-docx` — Generates .docx Word documents
- `Pillow` — Handles image dimensions for proper sizing in the report

### 3. opencode

```bash
# Install opencode (see https://opencode.ai for instructions)
# The template includes opencode.json configuration
```

### 4. Node.js / npm (for .opencode plugins)

```bash
# Check if Node.js is installed
node --version && npm --version

# If not installed (Ubuntu/Debian):
sudo apt install nodejs npm

# If not installed (macOS with Homebrew):
brew install node

# If not installed (Windows):
# Download from https://nodejs.org/
```

### 5. Your Development Tool

Depending on your assignment:
- **emu8086** — For 8086 assembly programs (Windows)
- **GCC/G++** — For C/C++ programs
- **Python interpreter** — For Python programs
- **JDK** — For Java programs
- **VS Code / other IDE** — For general development

## Step-by-Step Usage

### Step 1: Copy the Template

```bash
# Copy to your new assignment folder
cp -r assignment-template/ /path/to/your/new-assignment/
cd /path/to/your/new-assignment/
```

Or on Windows (in File Explorer):
- Copy the `assignment-template` folder
- Paste it into your course folder
- Rename it to match your assignment

### Step 2: Run the Setup Script

```bash
python3 setup.py
```

The script will ask you for:

| Field | Required? | Example |
|---|---|---|
| Student Name | Yes | MD RAKIBUL HASAN MOLLA |
| Student ID | Yes | 25525202004 |
| University Name | Yes | Bangladesh University of Professionals |
| Course Code | Yes | MCS2214 |
| Course Name | Yes | Advanced Reverse Engineering |
| Assignment Title | Yes | Calculate the Sum of the First N Fibonacci Numbers |
| Platform/Tool | Yes | emu8086 |
| Faculty Name | Optional | Dr. Smith |
| Faculty Designation | Optional | Associate Professor |
| Semester | Optional | Spring 2026 |
| Section | Optional | A |
| Submission Date | Optional | August 20, 2026 |

After setup, the script generates:
- `templates/report_config.json` — Your metadata
- `templates/task.md` — Filled-in task description
- `screenshots/` — Empty folder for screenshots
- `.opencode/` — Complete plugin/tool/skill structure with dependencies installed

### Step 3: Open in opencode

```bash
# Navigate to your assignment folder
cd /path/to/your/new-assignment/

# Open in opencode
opencode
```

When opencode opens, it automatically:
- Loads `.opencode/plugins/interaction-archiver.ts` (archives your session)
- Loads `.opencode/skills/assignment-mode/SKILL.md` (assignment workflow)
- Registers `.opencode/tools/screenshot.ts` (screenshot capture)
- Reads `AGENTS.md` (agent behavior rules)

### Step 4: Write Your Code

In opencode, say:

```
Write the code for my assignment. Read templates/task.md for requirements.
```

The AI will:
1. Read your assignment details from `templates/task.md`
2. Write the code in the appropriate language
3. Add proper comments and structure

### Step 5: Build and Run

Copy the generated code to your development tool:
- **emu8086**: Paste into the editor, click Emulate, then Run
- **Python**: Run with `python3 filename.py`
- **C/C++**: Compile with `gcc filename.c -o output`, then `./output`

### Step 6: Take Screenshots

Take screenshots of:
1. **Code view** (top half) → save as `screenshots/code_view.png`
2. **Code view** (bottom half) → save as `screenshots/code_view_2.png`
3. **Compilation output** → save as `screenshots/compile.png`
4. **Run button** (optional) → save as `screenshots/run.png`
5. **Console prompt** → save as `screenshots/run_start.png`
6. **Console output** → save as `screenshots/execution_output.png`
7. **Errors** (if any) → save as `screenshots/error1.png`

All screenshots must be **PNG format** and saved in the `screenshots/` folder.

Alternatively, use the screenshot tool in opencode:
```
Take a screenshot of the current screen
```

### Step 7: Generate the Report

In opencode, say:

```
Generate the DOCX report for my assignment.
Run: python3 assets/generate_report.py
```

Or run manually:

```bash
python3 assets/generate_report.py
```

The report is saved as `report_final.docx` in your assignment folder.

### Step 8: Review and Submit

1. Open `report_final.docx` in Microsoft Word or LibreOffice
2. Check that all screenshots are embedded correctly
3. Review the text for accuracy
4. Make any final edits if needed
5. Submit!

## The .opencode Directory

The `.opencode/` directory contains all opencode extensions that are auto-loaded when you open the project:

### Plugins

**interaction-archiver.ts** — Automatically archives all user prompts, AI responses, and todo updates to `.opencode-archive/`. This creates a complete history of your work session.

### Tools

**screenshot.ts** — A tool that captures the Windows desktop screen. It calls the PowerShell script `screenshot.ps1` and returns the image as an attachment. Use it by saying "Take a screenshot" in opencode.

### Scripts

**screenshot.ps1** — A PowerShell script that captures the primary monitor screen to a PNG file. This is called by the screenshot tool.

### Skills

**assignment-mode/SKILL.md** — A skill that activates when you mention assignment-related keywords. It provides the complete workflow: code writing → testing → screenshots → report generation.

## Customization

### Change University Logo

Replace `assets/bup_logo.png` with your university's logo. The report generator will use it on the cover page.

### Modify Report Sections

Edit `assets/generate_report.py` to:
- Add/remove sections
- Change formatting
- Customize the cover page
- Modify the instructions reference table

### Add New Screenshots

Place any PNG file in `screenshots/`. The report generator auto-detects these filenames:
- `code_view.png`, `code_view_2.png`
- `compile.png`, `run.png`, `run_start.png`
- `execution_output.png`, `error1.png`

Any other PNG files will be ignored.

### Add New Skills

Create a new SKILL.md file in `.opencode/skills/your-skill-name/SKILL.md`. opencode will auto-discover it.

## Troubleshooting

### "Configuration file not found"
Run `python3 setup.py` first to generate `templates/report_config.json`.

### "Permission denied" when saving report
Close the report file in Word/LibreOffice if it's open, then regenerate.

### Images not appearing in report
- Ensure screenshots are in `screenshots/` folder
- Ensure they are PNG format
- Ensure filenames match the expected names

### Pillow not installed
```bash
pip install Pillow
```

### python-docx not installed
```bash
pip install python-docx
```

### opencode plugins not loading
```bash
cd .opencode && npm install
```

### Screenshot tool not working
- Ensure you're on Windows (the tool uses PowerShell)
- Ensure `powershell.exe` is accessible from WSL
- Try running the script manually: `powershell.exe -File .opencode/scripts/screenshot.ps1 -OutputPath screenshots/test.png`
